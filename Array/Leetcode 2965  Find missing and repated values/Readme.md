# Explanation 
In this problem  we are given a matrix of size 
n×n . Each integer appears once accept one integer which appears twice and a integer 
is missing we need to find both the integers.

We have to initialize two for loops and use them as the co ordinates for our grid frequency table and increment the frequency then initialize another for loop and check what's the frequency of each element
