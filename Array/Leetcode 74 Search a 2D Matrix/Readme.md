# Leetcode 74 Search a 2D Matrix 
# Explanation 
In this problem we are given a matrix of size 
m×n with each row being sorted and in non decreasing order
we are also given a target and we have to return yes
if the target is present in the martix or else we need to return no.
# Intuition 
We use binary search in this problem to find the answer 
# Algorithm 
Initialize n and m with the length of rows and columns respectively and l and r with the first and last element respectively then we apply binary search to find the target 
# Complexity 
 Time Complexity : O(log(n))

 Space Complexity : O(1)
