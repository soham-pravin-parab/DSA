# Leetcode 136 single Number
# Explanation 
In this problem we are given a non zero array
and all the elements in the array appear twice
except one we need to return that single element 
# Intuition 
We use the XOR operator in this approach. 
# Algorithm 
1. Declare a XOR operator whit 0
2. Initialize a for loop raise the oprator with the i th element
3. return the operator 
# Complexity 
Time Complexity : O(n)

Space Complexity : O(1)
