# Leetcode 15 3sum
# Explanation 
In this problem we have been given an array and we have
to return a non duplicate triplets such that there sum is 0
# Intuition 
We check if the sum of any two elements gives the negative of a third element if it does we store it in a vector and then return it
# Algorithm 
# Complexity 
Time Complexity : O(nlog(n))

Space Complexity : O(n)
